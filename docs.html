Visão geral

A Gather 0.1 é a IA da categoria Desenvolvedores da Nathanael Industries responsável por criar, registrar e orquestrar as APIs usadas pelas outras IAs — Horácio (HoV 1.1), Miquéias (JpG 1.0) e Asafe (0.1). O Asafe cuida dos servidores onde as APIs rodam; a Gather cuida do contrato, das credenciais e da integração.

Escrevendo um pedido

O motor identifica no texto:

  • IA consumidora — pelo nome (Horácio, Miquéias, Asafe) ou palavras como “trading”, “infraestrutura”. Sem menção, a API fica para todas as IAs.
  • Recursos — cotações, ativos, ordens, carteiras, tarefas, eventos/agenda, lembretes, notificações, mensagens, cálculos, relatórios, servidores, logs, agentes, permissões, usuários, arquivos, registros, clima, notícias, pagamentos. Termos desconhecidos viram um recurso genérico.
  • Operações — listar, consultar, criar, atualizar, remover. “Gerenciar” ou “CRUD” gera todas.
  • Autenticação — padrão API Key; “JWT”/“token” → Bearer; “OAuth” → OAuth2; “pública” → sem auth.
  • Extras — “tempo real” adiciona stream SSE; “webhook” adiciona registro de webhooks.
  • Nome — texto entre aspas vira o nome da API.
"Painel Trader" — API de ordens e carteiras em tempo real para o Miquéias, com webhook

Manifesto de tools

Formato que qualquer IA da NI carrega para conhecer a API:

{
  "gather": "0.1",
  "api": "<slug>",
  "version": "0.1.0",
  "consumidor": "miqueias",
  "baseUrl": "https://api.nathanael.industries/<slug>/v1",
  "auth": { "type": "apiKey", "header": "X-Gather-Key", "credencial": "gather://credenciais/<slug>" },
  "tools": [
    {
      "name": "<slug>_listar_cotacoes",
      "description": "Listar cotações — GET /cotacoes",
      "input_schema": { "type": "object", "properties": { ... }, "required": [ ... ] },
      "x-http": { "method": "GET", "path": "/cotacoes" }
    }
  ]
}

Para executar uma tool, a IA monta a requisição com x-http: parâmetros entre chaves no caminho ({id}) saem do input; em GET o restante vira query string; em POST/PATCH vira o corpo JSON.

Autenticação

As chaves são emitidas em Credenciais, vinculadas a uma IA, uma API (ou todas) e um escopo:

readApenas GET.
writeLeitura e escrita.
adminTudo, incluindo operações administrativas futuras.
 
curl https://api.nathanael.industries/<slug>/v1/cotacoes \
  -H "X-Gather-Key: gth_live_..."

A chave completa aparece uma única vez. O console guarda somente o hash SHA-256, prefixo e sufixo.

Roteador

Quando uma IA descreve uma necessidade, a Gather interpreta o pedido, compara os recursos e termos com as APIs do catálogo e pontua cada uma (recursos em comum, termos, permissão da IA e status de publicação). Se nada atende, propõe criar a API.

Convenções

  • Rotas em português, plural e sem acento: /cotacoes, /tarefas/{id}.
  • Listagens retornam { "dados": [...], "total": n } com ?limite=&pagina=.
  • Criação responde 201; remoção responde 204.
  • Toda API expõe GET /health sem autenticação.
  • Base URL: https://api.nathanael.industries/<slug>/v<major>.

Limites da v0.1

  • O console roda inteiro no navegador; catálogo e credenciais ficam no localStorage. Use Exportar/Importar para backup.
  • O Playground e o Monitor usam respostas e métricas simuladas — ainda não há deploy real.
  • A interpretação de pedidos é por regras (dicionário de recursos e ações). Geração por LLM está prevista para a 0.3.
  • Deploy real das APIs depende do Asafe (infraestrutura), previsto para a 0.2.
