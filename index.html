O que a Gather faz

Gerenciadora e orquestradora de APIs da Nathanael Industries. Cada função abaixo já tem uma área no console.

Criação de APIs

Descreva o que a IA precisa; a Gather define recursos, rotas, autenticação e gera o código.

Emissão de chaves X-Gather-Key por IA, com escopo, revogação e registro de uso.

◉

Monitoramento

Seleção e compatibilidade

Roteador que indica qual API atende a necessidade de cada IA e padroniza formatos.

Pipeline

Da necessidade à API publicada

Uma IA (ou o Sr. Nathanael) pede uma capacidade. A Gather transforma o pedido em uma API completa.

Pedido

“Miquéias precisa de cotações em tempo real.”

Interpretação

Consumidor, recursos, operações, auth e extras são identificados.

Geração

OpenAPI 3.1, servidor Express, clientes JS/Python e tools.

Credencial

Chave emitida para a IA consumidora com escopo da API.

Publicação

Registro no catálogo e monitoramento contínuo.

Para as IAs

Manifesto de ferramentas

Cada API gerada vem com um manifesto gather.tools.json. Uma IA carrega o arquivo, recebe a lista de ferramentas com input_schema e passa a chamar a API sem código extra.

Formato do manifesto → 
// gather.tools.json — gerado para Miquéias
{
  "gather": "0.1",
  "api": "miqueias-api-de-cotacoes",
  "consumidor": "miqueias",
  "auth": { "type": "apiKey", "header": "X-Gather-Key" },
  "tools": [
    {
      "name": "miqueias_api_de_cotacoes_listar_cotacoes",
      "description": "Listar cotações — GET /cotacoes",
      "input_schema": {
        "type": "object",
        "properties": { "limite": { "type": "integer" } }
      }
    }
  ]
}
